## Usage

These pastebin codes can be used to test the `load_build` MCP tool:

```bash
curl -X POST http://localhost:3000/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"load_build","arguments":{"source":"uCLE0msa","buildName":"Test Build"}}}'
```

Expected response:
```json
{
  "success": true,
  "message": "Build 'Test Build' loaded successfully from pastebin code",
  "buildName": "Test Build",
  "statsAvailable": false,
  "sampleStats": {}
}
```
